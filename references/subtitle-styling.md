# 字幕版式：ASS 的坑与逐字弹的实现

`scripts/make_subs.py` 生成的是"每个字一个独立事件"的 ASS——每个字有自己的
出现时刻、位置、旋转角度、缩放动画。这样才有"蹦出来"的手感，也让每字能单独卡拍。

## 核心参数

```python
FS, PAD, GAP, ROW_Y = 88, 0, 10, 986     # 字号 / 留白 / 字间缝 / 底部行中心
TOP_Y, MID_Y = 118, 486                   # 顶部 / 中部行中心
TFS, TPAD, TGAP, TROW_Y = 150, 0, 14, 860
OUTLINE, SHADOW = 3.6, 2.4                # 描边 / 投影
CHUNK_MAX = 18                            # 每段最多几个字
MIN_STEP = 0.15                           # 每字最短间隔
REVEAL = 0.78                             # 出字窗口只占句长的前 78%
```

### REVEAL：这是"字幕比声音慢半拍"的根源

一句话有 4-5 秒，如果 13 个字均匀铺满 4.9 秒，每字 0.377 秒。
但中文句子是**前半句唱得快、末字拖长音**——均匀铺到句尾，越到后面越滞后。

实测案例：2:29 时唱到「气质跟脸庞」，字幕才出到第 5 个字。整句起点没错
（和原片换行点一致），错在句内速率。

改成 `plan_end = start + (end - start) * 0.78` 后，步长从 0.377 缩到 0.307，
同一时刻出到第 6 字，并在 0.16 秒后追上唱词。

**调参经验**：

| REVEAL | 效果 |
|---|---|
| 1.00 | 铺满整句，句尾严重滞后 |
| 0.85 | 改善有限 |
| **0.78** | 大多数流行歌的甜点 |
| 0.65 | 文本会跑到唱词前面，观感变成"抢" |

### hold：句尾别再额外留白

```python
hold = 0.0 if title else 0.06
```

`REVEAL` 之后那 22% 就是末字的停留时间。再额外留 0.3s 会让上一句和下一句
重叠 0.3 秒——两条字幕同时在屏上，看起来正是"字幕和画面没对上"。


### CHUNK_MAX 必须够大

`CHUNK_MAX` 是"一句最多几个字排在同一行"。超过就均分成多段**轮流**显示。

设成 12 时，13 字的句子会被拆成 `12 + 1`——前 12 字显示，最后孤零零一个"逛"字
单独闪一下。看起来像 bug。

设成 18 时，17 字的句子能完整一行，观感才对。

**判断标准**：`最长句的字数 ≤ CHUNK_MAX`。中文流行歌词单句很少超过 18 字，
所以 18 是安全值。如果某首歌有更长的句子，按 `CHUNK_MAX = 最长句字数` 设。

### BorderStyle：描边不要色块

| BorderStyle | 效果 | 适用 |
|---|---|---|
| `1` | 描边 + 投影 | **推荐**。不遮挡画面，任何底色上都能读 |
| `3` | 不透明底框 | 复古 MV 感，但每个字自带一块底，整句等于一排方块 |

色块模式下 `PAD` 要设成 8-10（框的留白），字号略小（82），描边值即框厚度（9）。
`make_subs.py --theme box` 就是这套。

**实测结论**：色块模式在深色动画画面上极其难读，且"一排方块"的观感很差。
除非用户明确要这种风格，否则用 `cut`。

### 三种文本模式

| 模式 | 字段 | 行为 | 用途 |
|---|---|---|---|
| 逐字 | （默认） | 每字独立事件、独立动画、按拍点弹出 | 歌词正文 |
| 整块 | `title: true` | 所有字同时出现，整块缩放淡入 | 片头歌名、片尾署名 |
| 整行 | `block: true` | 单条事件、保留空格、不拆字 | 词曲署名这类小字 |

**片尾署名必须用整块模式。** 逐字弹出的情况下，"周杰伦"三个字按拍点间隔
要 2.2 秒才齐，等第三个字出现时画面已经淡出大半，署名等于没看清。

`title` 模式的淡出用 `fad(420, 520)`——出场 420ms、退场 520ms。退场必须留时间，
否则会在画面还亮着的时候"啪"地消失。

## 逐条覆盖字段

`lines.json` 每条可以覆盖版式：

```json
{
  "start": 0.85, "end": 7.05,
  "text": "园游会",
  "title": true,
  "y": 505,      // 覆盖行中心 Y
  "fs": 208,     // 覆盖字号
  "sp": 24,      // 覆盖字距
  "bord": 6.4,   // 覆盖描边
  "fade": 600    // block 模式的淡入淡出毫秒（单值，进出相同）
}
```

这也解决了"标题压脸"的问题：不靠改全局行高，而是逐条指定位置。

## 位置与画面联动

`place` 有三个值：`T`（顶部 y=118）、`M`（中部 y=486）、`B`（底部 y=986）。

`build_lines.py` 会为每句歌词找它**中点所在的那个镜头**，继承该镜头的 `place`。
所以分镜表里的 `place` 列要按"这一镜的画面构图"来填：

- 人物在画面下半部 → 字幕放 `T`
- 人物在画面中部、上下都空 → 字幕放 `B`，或 `T`（看留白哪边大）
- 大面积空景（天空、水面、远景）→ 随便，选和前后镜不同的，制造节奏

**不要全片用一个位置。** 镜头在切，字幕位置不切，会有强烈的"贴纸"感。

## ASS 语法要点

### 颜色是 BGR 倒序

```
&HAABBGGRR      # AA=透明度(00 不透明 FF 全透明)
&HBBGGRR&       # 内联 tag 用的短格式
```

暖白 `rgb(255,250,240)` → `&HF0FAFF&`。写反了会变成蓝色。

### Style 行的字段顺序

```
Name, Fontname, Fontsize, PrimaryColour, SecondaryColour, OutlineColour, BackColour,
Bold, Italic, Underline, StrikeOut, ScaleX, ScaleY, Spacing, Angle,
BorderStyle, Outline, Shadow, Alignment, MarginL, MarginR, MarginV, Encoding
```

`Alignment=5` 表示 `\pos` 是文字中心点（`an5`）。要用 `an1`（左下角对齐）
做片头标题时，Style 里写 `7` 或在内联 tag 里写 `\an1`。

### fontsdir 必须绝对路径

```bash
# 会静默失败，字体退回默认黑体，且不报错
ass=subs.ass:fontsdir=assets/fonts

# 正确
ass=subs.ass:fontsdir='/abs/path/to/assets/fonts'
```

而且 `fontsdir` 里的字体**文件名不必等于 Fontname**，但 ASS 里的 `Fontname`
必须和系统注册名一致。ZCOOL KuaiLe 的注册名是 `ZCOOL KuaiLe`（带空格）。

### \t 动画的写法

```
\fscx50\fscy50\t(0,80,\fscx118\fscy118)\t(80,170,\fscx100\fscy100)
```

三个关键帧：起始 50% → 80ms 时过度放大到 118% → 170ms 回落到 100%。
这个"过冲"是"弹"的手感来源。省掉过冲就变成普通的放大淡入。

### 字的转场

```python
out_ms = 150 if 该字后面还有字 else 0
anim += "\\fad(55,%d)" % out_ms
```

句中字只淡入 55ms、淡出 150ms（让下一个字盖上来时前一个字已经开始退）；
句末字不淡出（`0`），直接保留到整句结束。否则句尾会一闪。

## 验收方法

```bash
# 抽一帧看字
ffmpeg -ss 100 -i final.mp4 -frames:v 1 check.png
```

重点看：

- 整句是否在一行内（不是 12+1）
- 有没有压住人脸
- 描边在深色底上够不够（不够就加 `bord`）
- 字距是否均匀（`GAP` 与 `sp` 别打架）
