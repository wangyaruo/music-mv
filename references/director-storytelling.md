# 导演式视觉构思：从歌词语义到连贯画面

本参考解决的是“拍什么、为什么这样拍”，不是继续扩充物件库。先完成导演构思，再决定角色、场景、物件和生成方式。**载体是创作结果，不是用户必须预先选择的答案。**

## 一、导演先回答四个问题

在出分镜前，同时阅读校订后的歌词、拍点网格、歌曲结构、风格候选和用户约束，回答：

1. **这首歌真正说了什么？**用一句 `logline` 概括关系、处境或心理变化，不复述歌词名词。
2. **情绪如何变化？**至少拆成 3 个阶段，写清每阶段的情绪、视觉策略和音乐证据。
3. **节奏如何改变观看方式？**把段落能量映射为镜头密度、动作幅度、停留时间和转场方式，而不是所有镜头同一节奏。
4. **为什么是这个视觉世界？**说明场景、角色、色彩、材质和构图与主题的关系，不能只因为“好看”或“最近流行”。

允许故事片、心理空间、视觉诗、物件叙事、界面装置等不同答案。抽象歌词不强制补写人物爱情，也不得以“没有叙事”为理由拼随机意象。

## 二、先给 2–3 套真正不同的概念

每套候选必须包含：

- 一句话 premise / logline；
- 视觉世界与情绪弧线；
- 主角是否必要，或由空间、光影、身体局部、物件承担主体；
- 3 个以上关键场景及动作；
- 贯穿视觉母题及其状态变化；
- 转场与节奏规则；
- 风格与成本倾向；
- 对整首歌词的覆盖方式。

候选差异应来自**叙事视角和视觉机制**，不是同一方案换三种色调。例如：

- 以“无人房间的光线变化”表现放下；
- 以“一个人重复整理同一张桌子”表现无法结束；
- 以“聊天记录里不断重写的句子”表现迟疑。

AI 负责提出和解释方案，用户负责选择与约束。不要反过来要求用户先从物件菜单中选答案。

## 三、从概念展开视觉总纲

选定后写 `out/director.json`，必须包含：

| 模块 | 要回答的问题 |
|---|---|
| `themes` / `semantic_thesis` | 歌曲的核心主题与潜台词是什么 |
| `emotional_arc` | 情绪至少怎样经过 3 个阶段，音乐证据是什么 |
| `rhythm_arc` | 各段能量如何改变镜头密度、动作与转场 |
| `visual_world` | 场景体系、色板、材质和风格锚点是什么 |
| `character_roles` | 谁承担动作；没有人物时由什么承担 |
| `scenes` | 每个场景的目的、动作和可见变化是什么 |
| `motifs` | 哪些意象贯穿、为何出现、状态如何变化 |
| `transitions` | 镜头为什么在此刻衔接，保持哪一种连续性 |
| `coherence_rules` | 角色、空间、物件和风格哪些规则不能中途改变 |
| `coverage` | 每句歌词的视觉意图、场景和具体变化是什么 |

### 角色是选项，不是默认答案

- 需要人物时，明确角色的叙事功能、视觉锚点和动作逻辑，而不只是年龄、发型和服装。
- 不需要人物时，填写 `absence_strategy`，说明为何空间、光影、手、背影、物件或运动更有表达力。
- 不要为了“看起来像 MV”强行加入情侣、孤独行人或下雨街头。

### 母题必须有功能，不能逐句换物件

每个母题标注一种功能：

- `anchor`：贯穿和统一全片；
- `contrast`：制造两种状态的对照；
- `transition`：连接场景或时间；
- `texture`：提供氛围和材料感。

贯穿母题要有至少两个可区分状态。全片控制在 0–4 个核心母题；如果每句都引入一个新物件，说明没有形成视觉结构。

### 场景必须发生可见变化

写清角色动作、物件变化、光线变化、空间变化或关系变化。只写“雨夜、房间、街道、海边”不是分镜，只是地点清单。

## 四、抽象歌词的四种表达路径

1. **心理空间**：用同一空间的开放、封闭、倾斜、远近、明暗表现心理变化。
2. **自然与材料**：用光、风、水、尘、纸、玻璃等材料的物理变化承载情绪，不要求每件物品都有固定象征。
3. **身体与动作**：用手、脚步、背影、呼吸、停顿和视线代替完整人物叙事。
4. **视觉规则**：用界面、计数、排列、重复、遮罩或图形变化形成可学习的观看规则。需要时再参考 `ui-narrative.md`，不要把 UI 当默认答案。

抽象不等于无逻辑。仍然需要情绪阶段、视觉动机、贯穿规则和递进关系。

## 五、镜头变化与衔接

每个转场至少保持一种连续性：

- **语义连续**：前一句的疑问在后一句得到动作回应；
- **情绪连续**：色彩、光线或空间沿同一情绪方向变化；
- **节奏连续**：动作接触点、脚步、切点或停顿对齐音乐；
- **视觉连续**：形状、方向、运动、遮挡或构图形成匹配；
- **空间连续**：前后镜头保持可理解的位置关系。

不要给所有转场套同一种叠化。允许匹配剪辑、动作接续、物件遮挡、同构构图、光线桥接和拍点硬切，但必须说明动机。

## 六、导演规划的使用方式

```bash
# 只生成空白结构和逐句覆盖清单，AI 必须自行填写创意内容
python scripts/director_plan.py scaffold --lyrics lyrics.txt \
  --title "歌名" -o out/director.json

# 检查结构、状态和歌词覆盖；不评价审美质量
python scripts/director_plan.py check out/director.json --lyrics lyrics.txt

# 生成给用户确认的导演阐述
python scripts/director_plan.py review out/director.json \
  --lyrics lyrics.txt -o out/director.md
```

`check` 通过只表示结构完整，不证明创意好。导演评审仍需检查：是否真正理解歌词、是否机械象征、是否有更好的视觉选择、是否保持统一风格。

## 七、验收清单

- [ ] 一句话导演阐述不复述歌词表面名词，能解释全片视觉选择。
- [ ] 情绪至少 3 阶段，且每阶段有音乐证据和不同视觉策略。
- [ ] 节奏变化同时影响镜头密度、动作幅度或停留时间。
- [ ] 角色、场景和母题都有叙事功能；无人物方案也有明确主体。
- [ ] 每句歌词都有视觉意图和可见变化，没有逐句换物件或逐句换场景。
- [ ] 转场至少保持一种语义、情绪、节奏、视觉或空间连续性。
- [ ] 复唱推进状态，而不是复制第一次的构图和动作。
- [ ] 全片角色、色板、空间逻辑和材质统一，没有无动机的风格孤岛。
- [ ] 不用“歌词抽象”解释随机拼贴，也不为了完整故事强行添加爱情或反转。

## 八、常见失败

| 失败 | 表现 | 修正 |
|---|---|---|
| 关键词配图 | 雨就画雨、花就画花、夜就画夜 | 改写为关系、动作或状态变化 |
| 物件堆砌 | 每句一个新道具，物件之间没有规则 | 合并为少量母题并设计状态轨迹 |
| 强行叙事 | 抽象歌词被硬写成相遇—争吵—分手 | 改用心理空间、材料或动作结构 |
| 风格拼贴 | 每镜换画风、换角色比例、换材质 | 在 visual_world 和 coherence_rules 中锁死 |
| 转场无动机 | 所有镜头都叠化或随机 zoompan | 为每次衔接指定连续性和音乐触发点 |
| 只有氛围没有递进 | 全片都是漂亮空镜和慢推 | 为每句补充可见变化，并为段落设置视觉转折 |
