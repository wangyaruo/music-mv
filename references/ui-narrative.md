# 叙事装置：把抽象情绪变成能读的界面

> 本文只是导演工具箱中的一种路径，不是默认答案。先按
> [director-storytelling.md](director-storytelling.md) 完成语义、情绪和节奏分析；
> 只有量化 UI 确实更适合歌曲时才采用本文。无人物、无实物、非界面方案同样成立。

一首抒情歌最难的地方不是画得好看，是**画面和歌词说的不是一件事**。
"我爱你但你不知道"这种句子，直接画一个人望天就废了——观众只看到一个人站着。

当抽象情绪需要可计量、可操作的载体时，一种有效方法是：**先设计量化规则，再决定画什么。**
本文把这个方法拆成可复用的装置库和选型规则。

> **来源**：本文从一支抖音像素 MV（周杰伦《一点点》，3:34，28 镜）逆向拆解而来。
> 那支片子的全部力气都花在"把恋爱做成游戏界面"上，画面本身大量是静态的。

---

## 一、核心原则：情绪必须先被计量，才能被看见

对比两句话：

- ❌ "他越来越不陪她了" —— 无法拍
- ✅ "他的时间分配：工作 100%，朋友 70%，游戏 30%，她 0%" —— 一条空条就能拍

第二句不是画面描述，是**数据描述**。数据能画成条、能画成表、能跳数字、能删掉。
抽象情绪一旦变成数据，画面问题就变成了排版问题，成本降一个数量级。

**判定标准**：只有当一句歌词适合用"它在什么单位下是多少"来表达时，才选择量化装置；
如果数字不能增加语义，不要硬造指标，改用空间、光影、动作或材料等导演路径。

---

## 二、装置库

每个装置 = 一套界面的隐喻 + 一种可读的量化。挑 2–4 个贯穿全片，不要贪多。

| 装置 | 承载的情绪 | 界面形态 | 关键动作 |
|---|---|---|---|
| **属性/时间面板** | 投入失衡、冷落 | 4–6 条横条，一条近乎空 | 条填充/缩短 |
| **找不同** | 毫无改变 | 左右两格 + "差异 N 处" | 盖章、计数定格 |
| **格斗 VS** | 争吵、冷战 | 红蓝分屏、血条、ROUND N、时钟 | 血条掉、回合数加 |
| **清单/待办** | 未兑现的承诺 | 一张纸，勾选框 | 勾选数停在 0 |
| **搜索 + 0 结果** | 消失、被抹去 | 搜索框 + 结果列表 | 输入名字→无结果 |
| **编辑器/地图** | 关系的空间结构 | 关卡编辑器、人物点位 | 标"已删除"、变虚线 |
| **进度条** | 关系推进/卡住 | 加载条、存档条 | 卡在 99%、无存档点 |
| **聊天/通话记录** | 疏远 | 消息列表、时间戳 | 时间戳越来越晚 |
| **播放/阅读计数** | 单向付出 | "播放 0 次""已读未回" | 数字不动 |
| **相册/云盘** | 回忆失真 | 缩略图墙、文件列表 | 分辨率降低、占位符 |
| **日历** | 一再推迟 | 月视图、日程格 | 同一格被划掉三次 |

**选择顺序**：优先选"观众一眼就懂规则"的装置（找不同、血条、进度条），
其次才是有学习成本的（编辑器、地图）。

---

## 三、装置要撑起三段结构，不能只当道具

只用一次的装置是道具，用三次以上才是系统。标准弧线：

1. **立规矩**（前 1/3）：用最直白的一镜教会观众怎么读这个界面。
   例：时间面板第一次出现，"工作满格、她空条"——观众立刻学会"条=陪伴"。
2. **累积**（中 1/3）：同一套界面反复出现，数值一次次变差。
   观众开始预期"这次她又会少一格"，预期本身就是情绪。
3. **反转或崩塌**（后 1/3）：用**同一套界面**做一件规则之外的事。
   例：编辑器里搜索"她"→ 0 个结果，人形变虚线标"已删除"。
   如果反转用的是新装置，前面的教学就白做了。

**验收**：把中间段任意一镜的字幕遮住，还能读出情绪吗？
读不出，说明装置没起作用，只是在配图。

## 四、成本：这条路比出图便宜一个量级

| 路线 | 主要成本 | 单镜成本 |
|---|---|---|
| 全 AI 出图 + 图生视频 | 每镜一张图 + 一段视频 | 高（约 90 credits/镜） |
| **UI 装置叙事** | 一套 UI 组件，全片复用 | 低（静态场景 + 数值动效） |

因为界面元素在镜头间**尺寸完全一致**，可以做成一套组件反复调用：
对话框、进度条、列表页、HUD 各做一次，之后只改文字和数值。

代价是：**你必须先把这套 UI 设计出来**。这是前置的一次性投入，
设计没做好，后面 30 镜全是同一个面板换字，会非常单调。

## 五、如果选像素风：实测参数

以下是从参考片实测的参数，可直接照抄。

| 项 | 值 | 说明 |
|---|---|---|
| 像素格 | 3×3 | 用自相关测列/行能量周期得到，别靠眼睛 |
| 虚拟画布 | 约 427×240 | 垂直精确 240 行；放大 3 倍输出 1280×720 |
| 输出 | 1280×720 / 30fps | 抖音横版够用 |
| 中文像素字体 | 虚拟画布上 11–12px | 实际渲染约 34px 高 |
| 转场 | 硬切为主 | 叠化在像素风里容易糊，慎用 |

**必须做的三件事**：

1. **渐变用棋盘抖动（dither）分级**，不要用高斯模糊——模糊会立刻暴露"这不是像素画"。
2. **常驻 HUD**：左上角固定"片名 + 歌手 + 小图标"。它同时兼任水印和游戏标题条，
   一物三用，省掉反复起标题。
3. **底部对话框承载歌词**：深色底、双层描边、左上角挂说话人标签（他/她）。
   字幕永远在框里，不压主体，也天然解决了"字幕位置跟画面打架"的问题。

**别做的事**：

- 别给高清素材套 pixelate 滤镜冒充像素画。判据是色板：真像素画的色数是人工限制的，
  滤镜产物在每格里仍保留连续色阶。观众说不清原因，但会觉得"脏"。
- 别在 1280 宽下画 1px 线条——放大 3 倍后会变成 3px 的糊边。

## 六、动效清单（不需要新画面）

装置类镜头靠这些动效撑住 4–8 秒，不需要重新出图：

- 条形填充（缓动 0.6–1.2s，末尾轻微回弹）
- 数字滚动（计数到 0 时停顿 0.3s 再定格，停顿比数字本身更有戏）
- 面板滑入/弹出（位移 40–80px，配 3 帧的残影）
- 印章砸下（下落 + 轻微弹跳 + 短暂缩放）
- 列表项被划掉/变灰/标删除
- 光标闪烁、加载点循环
- 速度线、粒子向心/离心（表现被拉扯、崩塌）

**长镜不是问题**：参考片最长一镜 26.7 秒，靠 UI 数值演化扛住。
装置类分镜允许 8–12 秒，不要为了"卡点"硬切，切碎了观众读不完信息。

## 七、踩坑

| 现象 | 原因 |
|---|---|
| 观众看不懂在表达什么 | 装置没教学，直接上了隐喻 |
| 每镜都像 PPT | 装置只用一次，没有累积和反转 |
| 越看越像模板 | UI 组件尺寸/字号不统一，或全片只有一个面板 |
| 情绪没落地 | 只做了"呈现"，没做"反转"，结尾还在展示数据 |
| 像素风看着脏 | 套了 pixelate 滤镜，或画布分辨率与放大倍数不匹配 |

---

## 八、交付前自查

- [ ] 每个装置至少出现 2 次，且有明确的"变差"轨迹
- [ ] 遮住字幕抽 3 镜，情绪仍可读
- [ ] 反转发生在同一套装置内，不是新开一个界面
- [ ] UI 组件在镜头间尺寸、字号、描边完全一致
- [ ] 像素风：随机抽 3 帧放大 8 倍，像素格是 3×3 且边缘无抗锯齿
- [ ] 常驻 HUD 在淡出前完整可见 ≥3s
